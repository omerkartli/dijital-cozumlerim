# Dijital Çözümlerim

Etkinlikler için dijital çözümler: düğün davetiyesi, davetlilerin fotoğraf
yüklediği moderasyonlu galeri ve bunları yöneten panel.

| Sayfa | Ne işe yarar |
|---|---|
| `index.html` | Vitrin: hangi çözümler var |
| `davetiye.html` | Dijital davetiye demosu (kurgusal bilgiler) |
| `etkinlik.html?slug=…` | Davetlilerin fotoğraf yüklediği ve galeriyi gezdiği sayfa |
| `admin.html` | Etkinlik, onay ve arşiv yönetimi |

Backend ayrı bir repoda: [`kisisel-sayfam-backend`](https://github.com/omerkartli/kisisel-sayfam-backend).
Çalışma kuralları ve tuzaklar için `NOTES.md`.

Bu proje `kisisel-sayfam` reposundan ayrıldı; kişisel sayfa orada kalmaya
devam ediyor.
